# Actividad uno
Desarrollo de la actividad uno: patrones de diseno.

## Estructura
El codigo de los ejercicios se encuentra en una carpeta por cada escenario del ejercicio e.g. scenarioOne, estas se encuentran dentro de la carpeta src.

Cada ejercicio cuenta con su documentacion dentro de una carpeta docs y su codigo dentro de la carpeta src.

## Como correr las apps
para correr cada ejercicio puedes correr el comando `npm run` y el nombre del escenario desde el root de este proyecto e.g `npm run scenarioTwo`
